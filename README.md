# Semiología Práctica — Videoaula premium

Repositório inicial de produção para uma videoaula completa em espanhol sobre derrame pleural, neumotórax, motivo de consulta cardiovascular e insuficiencia cardíaca.

## Insumos

- `assets/narracao_es.flac`: locução original sem perdas (duração aproximada: 14m24,5s). Arquivo convertido de WAV para FLAC para facilitar upload ao GitHub, sem perda de qualidade.
- `assets/roteiro_es.txt`: roteiro integral da locução.
- `assets/infografico_referencia.jpg`: referência de conteúdo e hierarquia visual. **Não usar recortes deste arquivo na videoaula.**
- `PROMPT_CODEX.md`: briefing técnico e criativo de implementação para o Codex.

## Primeira tarefa

Após enviar os arquivos ao GitHub e criar o primeiro commit, iniciar um ambiente Codex Cloud com este repositório. Enviar ao Codex: **"Leia PROMPT_CODEX.md e execute integralmente a implementação descrita, criando o projeto do zero. Não use screenshots/recortes do infográfico no vídeo."**

O projeto de vídeo será desenvolvido pelo Codex a partir desses arquivos de entrada. Este pacote não contém um vídeo pronto.
